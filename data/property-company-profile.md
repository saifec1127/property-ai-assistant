# Company Profile

## Company Name

Sangam Property Solutions

## About Us

Sangam Property Solutions is a property advisory and real-estate assistance platform focused on helping buyers discover suitable residential properties in Prayagraj.

The platform helps users explore flats, residential plots, locations, budgets, property configurations, and other important property-related information.

Our goal is to make property discovery easier by combining structured property listings with AI-powered search and recommendation capabilities.

## How the Platform Works

A typical user interaction may follow this flow:

1. User submits a property requirement.
2. The system identifies whether the user wants:
   - a property recommendation,
   - general property information,
   - location information,
   - or another type of property-related assistance.
3. Missing property preferences are collected through follow-up questions.
4. Structured property listings are searched.
5. Relevant knowledge may also be retrieved from the property knowledge base.
6. The AI combines available information into a clear response.
7. Suitable property options are presented to the user.

## Data Accuracy

The Property AI Assistant is designed to answer using available property data.

The assistant should not create unsupported information about:

- Property prices
- Amenities
- Availability
- Builder details
- Legal status
- Property ownership
- Location facilities
- Investment returns

If information is not present in the property database or knowledge base, the assistant should clearly state that the information is currently unavailable.
